# Changelog

All notable user-facing changes are documented here. The project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and will use semantic
version tags for public releases.

## [Unreleased]

- Interactive connector setup, safe readiness checks, and one-command build/flash tooling.
- Minimal authenticated command-line TV remote.
- Public compatibility, troubleshooting, security, and contribution guides.
- Cross-platform bootstrap scripts and automated Python/firmware validation.

- The root documentation now starts with the standalone ATOMS3U TV connector;
  the full voice-agent stack is presented as an optional advanced integration.
